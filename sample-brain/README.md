# Sample brain

A made-up second brain so live-agent works on first run. Everything here is fake.

- `raw/`: quick notes as they come in (the agent saves here; a tidy job turns them into wiki pages).
- `wiki/`: tidy pages, one topic each. The agent answers from here.
- `projects/`: one page per project. The agent answers from here too.

Point `brainPath` in `live-agent.config.json` at your own folder to use your notes.
