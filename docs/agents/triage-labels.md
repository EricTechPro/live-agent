# Triage labels

Status values used on the `**Status:**` line of each ticket.

| Role | Status string | Meaning |
|---|---|---|
| needs-triage | `needs-triage` | Not yet looked at |
| needs-info | `needs-info` | Waiting on an answer from Eric |
| ready-for-agent | `ready-for-agent` | Fully specified, an agent can build it |
| ready-for-human | `ready-for-human` | Needs a person (keys, signing, recording) |
| wontfix | `wontfix` | Will not be done |
| done | `done` | Built, tested, boxes ticked |
