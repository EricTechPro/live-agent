Get your Gemini key · 2 min

One key runs it all: the voice, the notes and the helper.

  1. Open Google AI Studio and sign in with Google.
  2. Accept the terms (first visit only). Tick the box, press Continue.
  3. Find API keys. Already see a key? Skip to step 5.
  4. Press Create API key. Name it live-agent, pick a project, press Create key.
  5. Copy the key. It's a long string that starts with AIza.
  6. Paste it in the installer at Paste your Gemini key. Nothing shows while you paste. That's on purpose.

Skipped it, or got a new key? Put it after GEMINI_API_KEY= in this file, then quit and reopen the app:

open -e ~/Desktop/live-agent/.env
Keep the key secret. Never paste it in a chat, a screenshot or a git repo. If it leaks, delete it in AI Studio and make a new one. The free tier is enough to try it.
What the installer does
  • Downloads the ready-built app. No build.
  • Makes ~/Desktop/live-agent with sample notes.
  • Saves your key there. Only you can read it.
  • Runs the doctor: key, mic, LiveKit.
  • Opens the app. A setup chat asks 4 questions.

Help

Something not working? The doctor checks your setup and prints one fix per problem.

Fix common problems · 10 fixes

The installer runs the doctor. To run it again:

LIVE_AGENT_HOME=~/Desktop/live-agent /Applications/live-agent.app/Contents/MacOS/live-agent-core doctor

Installed to ~/Applications? Use that path. Key, mic and LiveKit must pass. Helpers only fail when turned on.

"No Gemini key found."

Open the key file and put your key after GEMINI_API_KEY=. Then quit and reopen the app.

open -e ~/Desktop/live-agent/.env
"Gemini key is not valid."

Make a new key in AI Studio and paste it in .env. If the doctor says "may not use the Gemini API", make the key in AI Studio, not Google Cloud.

"Key works but is over its quota right now."

Wait a minute and try again, or check your quota in AI Studio.

"No microphone found."

Plug in a mic or headset, or pick one in System Settings › Sound › Input.

"LiveKit did not start" or "livekit-server not found."

Run the installer again. It puts LiveKit back inside the app. Working from the repo? brew install livekit.

"Gemini CLI is not installed."

Only needed for helper jobs. Install it once, then restart the app:

npm install -g @google/gemini-cli
The app stops with a config error.

The message names the bad field. Fix it in ~/Desktop/live-agent/live-agent.config.json, or delete the file to use the defaults.

"This build is for Apple Silicon Macs."

Jett runs on M1 or newer Macs only, for now. Intel Macs, Windows and Linux are not supported yet.

macOS asks for the mic again after an upgrade.

That's normal. Each build has a new signature. Press Allow.

It talks to itself, or cuts itself off.

It hears its own voice from your speakers. Use headphones.
